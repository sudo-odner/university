# Лабораторная работа № 5 — русский интерфейс к экспертной системе

**Дисциплина:** Системы искусственного интеллекта. **Предметная область варианта 8:** компьютерные вирусы.

## Цель и задача

Изучить лингвистические возможности Prolog и дополнить экспертные системы из лабораторной работы № 4 интерфейсом для запросов на русском языке. Пользователь вводит свободный текст во встроенном построчном редакторе. Программа выделяет ключевые слова, определяет действие и, если нужно, тип вредоносной программы.

## Анализ задания и выбор метода

Методика требует интерфейс на основе ключевых слов, поэтому полный грамматический разбор не нужен. Текст переводится в нижний регистр и разделяется на слова по пробелам и знакам препинания. Действие определяется по основам слов «опиши», «проверь» и «определи» с допустимыми вариантами. Названия типов распознаются по сочетаниям основ; порядок слов не важен. Более конкретное сочетание имеет приоритет. Такой подход поддерживает разные окончания русских слов, но не понимает произвольные синонимы и отрицания.

Встроенный редактор принимает несколько строк и позволяет просмотреть, заменить или удалить строку до отправки запроса. Это консольный текстовый редактор, реализованный средствами SWI-Prolog; графическое окно редактора Visual Prolog из методички здесь не используется.

## Структура программы

- [nl_logic.pl](nl_logic.pl): интерфейс плюс логическая экспертная система. Объекты описаны фактами `object/4` со списками признаков.
- [nl_rules.pl](nl_rules.pl): тот же интерфейс плюс продукционная экспертная система. Каждый тип задан отдельным правилом `diagnose/1`.

Обе программы самостоятельны: исходные файлы лабораторной работы № 4 для запуска не нужны. В них сохранены 12 учебных типов вредоносных программ и 10 двоичных признаков. Описания типов упрощены и не предназначены для реальной антивирусной диагностики.

Поток данных: `Русский текст → редактор → слова → ключевые слова → действие → база знаний / консультация → ответ`. Основные предикаты интерфейса: `editor/2`, `tokens/2`, `action/2`, `select_object/2`, `process_query/1` и `dispatch/2`. Тексты программ с комментариями находятся в указанных выше файлах.

## Возможности и примеры запросов

- «Расскажи о почтовом макровирусе» — показывает характерные признаки этого типа.
- «Проверь скрытный файловый вирус» — проводит консультацию по признакам и сравнивает заключение с указанным типом.
- «Определи тип программы» — запускает консультацию и выводит найденный тип.

В редакторе доступны команды `:показать`, `:заменить N текст`, `:удалить N`, `:очистить`, `:готово` и `:отмена`. Сначала вводится текст запроса, затем команда `:готово`.

## Запуск и машинные эксперименты

Из каталога лабораторной работы при установленном SWI-Prolog:

```sh
swipl -q -s nl_logic.pl -g main -t halt
swipl -q -s nl_rules.pl -g main -t halt
```

Для автоматической проверки 12 профилей из лабораторной работы № 4, неизвестного профиля, разбора русских фраз и операций редактора:

```sh
swipl -q -s nl_logic.pl -g run_all_tests -t halt
swipl -q -s nl_rules.pl -g run_all_tests -t halt
```

`run_all_tests/0` проходит успешно, только если все проверки возвращают ожидаемый результат. В текущей среде SWI-Prolog не установлен, поэтому выполнение тестов пока не подтверждено. Структуру программ можно проверить без интерпретатора: в каждом файле присутствуют 12 профилей, 10 признаков, словарь ключевых слов и предикаты редактора.

## Вывод

Ключевые слова позволяют связать свободный русский запрос с действием экспертной системы без жёсткого порядка слов. Построчный редактор даёт возможность исправить запрос до отправки. Ограничение метода — зависимость от словаря основ: незнакомые синонимы и сложные высказывания требуют его расширения.
